Suggested use in Vibe Apps
--------------------------
- Use the lineup sheets as source art to crop/select hero and boss assets.
- Use the background sheets for gameplay and victory/boss scenes.
- Use the FX sheets for slash, impact, spell, and summon effects.
- Use the hints sheets to crop individual hint cards/word images.

Notes
-----
- Most art is grouped into sheets rather than single-sprite files.
- You may want Codex or another tool to slice these sheets into individual PNG assets and generate a JSON manifest.
- File names are organized to be Vibe Apps upload friendly.
