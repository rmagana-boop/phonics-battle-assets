# Phonics Battle Assets

Production-ready art assets for the Vibe Apps phonics battle game.

## Raw URL pattern
After publishing this repository, replace `OWNER/REPO` in `asset-manifest.json`. Raw URLs will follow:

`https://raw.githubusercontent.com/OWNER/REPO/main/assets/hints/hint_cat.jpg`

## Folders
- `assets/heroes/` selectable ninja and magic heroes
- `assets/bosses/` victory battle enemies
- `assets/backgrounds/` gameplay and boss arenas
- `assets/fx/` ninja and magic attack effects
- `assets/hints/` individual phonics cue cards
- `asset-manifest.json` complete mapping for Vibe Apps

All assets are generated specifically for this game pack.
